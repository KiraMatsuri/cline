# 学生端编程教学助手

<p align="center"><b>面向高校编程教学的学生端 AI 助手</b><br/>实验任务 · 行为分析 · LLM 答疑 · 思考链隐藏 · 阻隔式干预</p>

> 本扩展基于 Apache-2.0 开源项目二次开发，供课程实验环境中的学生使用，与教学辅助系统（教师端 Web、teaching-server、学情看板）打通。

---

## ✨ 核心功能

### 📋 实验任务管理
- 一键拉取教师发布的实验任务（云端 teaching-server）
- 双击任务项自动创建源码文件到当前工作区
- 一键提交代码 + 行为日志到云端，获得 **AI 依赖度**反馈

### 🧑‍🎓 学生信息持久化
- 填写一次学号 / 姓名 / 班级，自动持久化到全局配置
- 每次进入「实验任务」窗口自动回填，无需重复填写

### 📚 学习进度与 Wiki 教学资料
- 设置当前教学周数（1~18 周）
- 按周自动拉取 Wiki 教学资料，注入 AI 上下文辅助答疑

### 🤖 LLM 答疑（可选）
- 教师端配置 LLM（如 DeepSeek），支持 karpathy 式工具调用答疑
- 与主对话模型解耦，可按教学场景独立选模型

### 🧠 教学干预与行为分析
- **隐藏思考链**：默认不显示模型推理过程，引导学生独立思考
- **AI 依赖度分析**：提交实验后反馈 AI 参与占比
- **阻隔式干预 + 实时倒计时**：检测到过度依赖 AI 时暂停辅助，并在顶部实时显示剩余锁定时间（跨对话生效，防止新建对话绕过）

### 📎 附件与资料
- 支持从服务器下载实验附件（PDF / 文本等）到工作区并打开

## ⚙️ 配置

在 VS Code 设置（`Ctrl + ,`）中搜索以下配置项：

| 配置项 | 说明 | 示例 |
| --- | --- | --- |
| `teaching.apiBase` / `clineTeaching.serverUrl` | 教学后端 API 地址（与「服务器设置」面板同源） | `http://localhost:4001` |
| `clineTeaching.currentWeek` | 学生当前学习周数（影响 Wiki 资料可见范围） | `1` ~ `18` |
| `clineTeaching.llmEnableTools` | 是否启用 LLM 工具调用答疑 | `false` |
| `clineTeaching.llmPresetModel` | LLM 答疑默认模型 | `deepseek-chat` |

> 主工具栏的「服务器设置」按钮可快速修改后端地址，保存后自动同步并刷新 Wiki 缓存。

## 📖 使用流程（学生）

1. 打开 VS Code，点击侧边栏 **「学生编程助手」图标** → 进入「实验任务」
2. 点击 **📥 获取实验任务**，从云端拉取任务列表
3. **双击**某个任务项，自动创建对应源码文件到当前工作区
4. 根据实验指导书 / 附件完成实验（可借助 AI 辅助）
5. 确认学生信息（首次填写后自动保存并回填）
6. 点击 **🚀 一键提交实验结果至云端**

## 🏗 架构

```
学生端编程教学助手（本扩展）
   │  HTTP (REST)
   ▼
teaching-server（教学后端：Express + SQLite + LLM/OCR）
   │
   ├── 教师端 Web（发布实验任务 / 管理教材资料）
   └── 学情看板（AI 依赖度 / 行为分析）
```

---

## 🔧 常见问题

- **获取任务失败 / 无法连接服务器**：检查「服务器设置」中的地址是否正确、教学后端是否已启动。
- **看不到思考链**：教学版默认隐藏模型思考链，属预期行为。
